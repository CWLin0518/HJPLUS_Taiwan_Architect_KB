# Taipei City Local Ordinances (臺北市地方自治法規)

## Skills

* [Taipei Building Attached Decorative Structures Review](臺北市建築物附置裝飾性構造物設計範例彙編/taipei-building-decorative-structures/SKILL.md) - This skill should be used when reviewing building attached non-structural decorative elements (frames, beams, columns, panels, louvers, railings, canopy/balcony/terrace/facade decorative features) in Taipei City per the 2024 Taipei City Building Attached Decorative Structure Design Exemplar Compilation (臺北市建築物附置裝飾性構造物設計範例彙編, Effective 2024-09-25). Includes porosity, projection, emergency opening, building area, FAR exemption, and height-slope restriction review.
